# design.md — дизайн-система tecxz5.github.io

Живой справочник по визуалу сайта. Правки вносишь — обновляй и этот файл.
Исходники правды: `site/src/style.css`, `site/index.html`, `site/src/main.js`, `site/src/generator.css`.

## Концепция

Бруталистичное моно: чёрный холст, белые рамки `2px solid #fff`, один кислотный
акцент `#cedb1a`. Только моноширинные шрифты, прямые углы (радиусы 0–4px и только
точечно), никакой «дружелюбности» — сайт выглядит как терминал с характером.
Без фреймворков: vanilla JS + Vite, живые WebGL-фоны на canvas.

Сайт устроен как презентация: секции-слайды, горизонтальный трек внутри
`#presentation`, всё скроллится трансформациями (не нативным scroll —
`scrollTo`/`location.hash`/`scrollY` не работают, только wheel-события через SlideJS).

## Палитра

| Токен / цвет | Значение | Где |
|---|---|---|
| `--accent` | `#cedb1a` | единственный акцент: шапка, бейджи, стрипсы, клин футера, рамки ховеров |
| `--loader-wave` | `#fbff9c` | блик-волна на бренде лоадера |
| фон | `#000` | body, карточки, инпуты генератора |
| текст | `#fff` | основной |
| `#050505` / `#0a0a0a` / `#111` / `#141414` | панели, демо-блоки, приподнятые поверхности |
| `#222` / `#333` / `#444` / `#555` | рамки инпутов, разделители, вторичные границы |
| `#777` / `#888` / `#aaa` / `#bbb` / `#ccc` / `#ddd` / `#eee` | приглушённый текст, подписи, метаданные (шкала «чем дальше от белого, тем второстепеннее») |
| `#ff5555` | только статус ошибки (`.is-unavailable` у last.fm-виджета) |
| `#55aaff` | только имя пользователя в чат-демо портфолио |
| `rgba(0,0,0,0.22)` + `blur(16px)` | стекло компактной шапки |
| `rgba(255,255,255,0.02…0.4)` | полупрозрачные рамки/подложки там, где белая рамка слишком жирная |

Правило: новый цвет — отклонение. Серые допустимы из таблицы выше, всё цветное
только через `var(--accent)`.

## Типографика

Четыре текстовых шрифта + иконочный. Пятый — отклонение.

| Шрифт | Загрузка | Роль |
|---|---|---|
| **Fira Mono** 500 | Google Fonts (`index.html`) | базовый шрифт body, основной текст, кнопки |
| **Martian Mono** 400–800 | Google Fonts | заголовки карточек, бейджи, акцентные подписи |
| **Feature Mono** Medium | локально `site/src/assets/fonts/FeatureMono-Medium.ttf` (`@font-face`, weight 500) | логотип `tecxz5`, бренд лоадера, врезка `t5` в заголовке bio |
| **Pixeloid Mono** 400 | локально `PixeloidMono.ttf` (`@font-face`) | только заголовки слайдов (`h2` у `.presentation-slide`) |
| Material Symbols Outlined | Google Fonts | иконки (`north_east`, `warning`, `description`, `casino`…) |

- `font-display: swap` у обоих локальных шрифтов.
- Глобально `user-select: none` (в генераторе инпутам возвращён `text`).
- Заголовки — `clamp()`, базовый текст фиксированный:
  - бренд лоадера: `clamp(40px, 11vw, 128px)`;
  - заголовки слайдов: `clamp(36px, 8vw, 88px)`, Pixeloid Mono, `line-height: 1`;
  - логотип шапки: `clamp(30px, 4vw, 48px)`;
  - лид-текст слайда: `clamp(18px, 3vw, 28px)`;
  - nav-ссылки: `clamp(12px, 1.2vw, 16px)`;
  - тело/мелочь: 16 / 13 / 12 / 11px, нижняя граница 9–10px (служебные подписи).

## Структура и навигация

`#fullpage` — три полноэкранные секции:

1. **`#top`** — пустая страница: bubbles-фон, хинт «просто листай вверх/вниз»
   (`mix-blend-mode: difference`), кнопка языка RU/EN.
2. **`#presentation`** — sticky-секция с горизонтальным треком `300vw`:
   слайды `#about`, `#services`, `#portfolio`. Трек — flex, переход
   `transform 0.54s cubic-bezier(0.76, 0, 0.24, 1)`. Контент слайдов повёрнут
   на `presentationAngle = -8°` (main.js). Поверх трека —
   `.presentation-strips`: 9 акцентных полос-«щепочек» с хаотичными углами
   (`rotate(-42deg…14deg)`), разбросаны по всей длине 300vw.
   Заголовки слайдов сдвинуты по-своему через `--slide-title-shift`.
3. **`#links`** — футер с 3D-губкой Менгера и акцентным клином.

### Шапка

- Фиксированная, акцентный фон + два повёрнутых псевдоэлемента
  (`::before` −5°, `::after` +5°) — эффект «мятой ленты»; углы и высота
  анимируются при скролле (`--header-top-angle` и т.д. пишутся из JS).
- Высота `clamp(60px, 5.2vw, 72px)`, отступ сверху `clamp(28px, 4.8vw, 52px)`.
- Компактное состояние (`.is-compact`): 46px (38px на мобиле), чёрное стекло
  `rgba(0,0,0,0.22)` + `blur(16px)`, псевдополосы схлопываются, текст белеет.
  Раскрывается обратно по ховер-зоне `.site-header-hover-zone`.
- Ссылки: чёрный текст на акценте; ховер/тач — инверсия `background: #000;
  color: var(--accent); padding: 8px 12px`; текущий раздел — белая плашка
  `background: #fff; color: #000; padding: 2px 8px`.
- Мобильное меню (≤720px): `.is-menu-open` растягивает шапку до
  `--mobile-menu-height: 270px`, nav — вертикальная сетка на
  `rgba(206,219,26,0.98)`, логотип центрируется абсолютным позиционированием.

## Фоны (canvas/WebGL)

| Секция | Эффект | Файл |
|---|---|---|
| `#top` | **Bubbles**: пиксельная сетка + всплывающие пузырьки «газировки» (до 48 шт.), лайм/белые на чёрном, реакция на мышь, искры при лопании | `bubbles.js` (фрагментный шейдер) |
| `#presentation` | **Symbols**: WebGL-сетка из Material Symbols, ячейка 92px, дрейфует с поворотом трека | `main.js` (`symbols-bg`) |
| `#links` | **Menger**: 3D-губка Менгера на чистом WebGL (Raymarching SDF) в пиксельной сетке, авто-вращение + бросок мышью/тачем с инерцией, прижата к футеру | `menger.js` |

Все фоны `pointer-events: none`, `aria-hidden="true"`.

## Компоненты

Общий язык: карточка = `#000` фон + `2px solid #fff` рамка; ховер =
`border-color: var(--accent)` + `translateY(-4px)` (только внутри
`@media (hover: hover) and (pointer: fine)`); бейдж = акцентный фон + чёрный текст.

### about (`#about`)

- `.about-grid`: `minmax(0, 1.15fr) minmax(0, 0.85fr)`, gap 16px, ширина
  `min(840px, 100%)`. `minmax(0, …)` обязателен — иначе nowrap-заголовки
  разъезжаются колонки.
- `.about-card--bio`: заголовок-врезка `.about-card__title` — inline-block,
  акцентный фон, чёрный текст, `t5` внутри в Feature Mono
  (`.about-card__title-accent`); теги стека (`about-tag`) прижаты к низу
  (`margin-top: auto`). Текст `about.desc` выдержан в самоироничном тоне:
  RU — «Вроде как что-то делаю, пусть этот сайт и доделал спустя полгода...»,
  EN — «I kinda build stuff, even if it took me half a year to finally finish this site...».
  Все ключи словарей RU и EN строго синхронизированы.
- `.about-card--lastfm`: бренд-бейдж Last.fm из спрайта `<symbol>`; статус +
  терминальный ASCII-спиннер на символах Брайля (`.lastfm-spinner`: бегущий цикл
  `⠋⠙⠹⠸⠼⠴⠦⠧⠇⠏` в акцентном цвете и шрифте Martian Mono; в паузе — застывает
  в статичную точку `·` цвета `#666`); обложка, трек/артист/альбом
  (лимиты усечения 48/36/34 символа + один `…`, в `title` — полное имя);
  ссылка на профиль внизу. Ошибка — красный `#ff5555` на статусе.
- Карточка не должна менять ширину от длины трека: `min-width: 0` на
  `.about-card`, `.about-card--lastfm`, `.lastfm-body`.

### services (`#services`)

- `.service-card` (2 шт., сетка `--two`): бейдж, summary с хинтом «нажми для
  подробностей»; клик раскрывает `.service-card__details` (`.is-expanded`)
  поверх затемняющего `.service-backdrop`; внутри — notice с иконкой
  `warning`, пункты с ценами (`.service-card__price-tag`), кнопка
  «Связаться в Telegram». Крестик закрытия — `&times;`. На мобиле карточки
  выстроены вертикально с комфортными паддингами.
- `.service-contract`: блок условий — пронумерованные пункты `01…05`
  (`.service-contract__num`, Martian Mono), пятый — широкий
  (`--wide`). Ссылка на PDF удалена с сайта и из репозитория (договор
  хранится и генерируется только локально).

### portfolio (`#portfolio`)

- `.portfolio-card` × 3:
  - Заголовок карточки `.portfolio-card__title` стилизован единообразно с bio
    в `about`: `display: inline-block`, акцентный фон `var(--accent)`, чёрный
    текст `#000`, шрифт Martian Mono.
  - Языковые бейджи удалены, карточки чистые.
  - Фиксированная высота блока демо `.portfolio-card__demo` (120px) с
    `overflow: hidden; flex-shrink: 0;` и внутренним автоскроллом логов, прижата
    к кнопкам футера карточки (`margin-top: auto; margin-bottom: 12px;`).
  - Проекты:
    - генератор фонов — мини-canvas 280×110 с WebGL-превью;
    - mus-downloader — CLI-демо на стеке Soulseek (`aioslsk`) + Deezer +
      mutagen + 24-bit FLAC, запуск `$ uv run dl <url> --flac`, автоскролл
      терминала `musCliBody.scrollTop = musCliBody.scrollHeight`;
    - боты — чат-виджет, `/slots` с Material-иконкой `casino`, автор бота —
      акцентный, юзера — `#55aaff`.
- На мобиле — одна карточка + пагинация точками (`.portfolio-dot.is-active`).

### Футер (`#links`)

- Полноэкранная секция, внизу — акцентный клин через `clip-path: polygon(...)`
  с асимметричными краями (`--footer-left-height` / `--footer-right-height`),
  учитывает `--safe-bottom`.
- 3D-губка Менгера на канвасе `#menger-bg` (WebGL, raymarching) рендерится
  за клином футера: нижняя четверть уходит под клин футера (`yShift` адаптируется
  под соотношение сторон экрана), а верхние ~3/4 возвышаются в черной зоне, не
  перекрывая хедер.
- Интерактивность: непрерывное авто-вращение в фоне; толчок/бросок мышью
  сообщает инерцию с постепенным затуханием трением; на таче вертикальные свайпы
  мгновенно отдаются нативному/слайдерному скроллу страницы (`isVerticalScroll`),
  а тач-вращение работает только по горизонтали (ось Y) без вертикальных перекосов.
- Панель: copyright-SVG слева, справа — крупные SVG-вордмарки Telegram/GitHub;
  ховер — `brightness(1.15)` (+ `scale(1.06)` на десктопе).

### Лоадер

- Три горизонтальные акцентные секции на весь экран; по `body.is-loaded`
  уезжают влево каскадом (bottom → middle → top, 1s / 1.12s / 1.24s, задержки
  0 / 0.16s / 0.34s).
- Бренд `tecxz5` (Feature Mono, `clamp(40px, 11vw, 128px)`) с бегущим бликом:
  дубль текста в `::after` цветом `--loader-wave`, mask-градиент 34%,
  анимация `loaderBrandWave 2.8s`.

### Иконки брендов

Единый zero-size `<svg>`-спрайт с `<symbol>` сразу после `<body>`,
использование через `<use href="#icon-…">`. Дублировать path по сайту нельзя.
Иконочный бейдж сохраняет подпись: `role="img"` + `aria-label` +
`data-i18n-aria`.

## Анимация

- Фирменная кривая: `cubic-bezier(0.76, 0, 0.24, 1)` — весь скролл-движок,
  шапка, лоадер, меню.
- Длительности: 0.2–0.32s микро-ховеры, 0.54s слайд трека, 1–1.24s выход
  лоадера, 2.8s волна бренда.
- Движение только через `transform`/`opacity`/`filter` + `will-change` на
  тяжёлом (трек, псевдополосы шапки).
- Тач-состояния дублируют ховеры классом `.is-touch-active`.

## Адаптив

- Брейкпоинты: **720px** (мобильное меню шапки, однокарточное портфолио,
  пагинация точками) и **600px** (уточнения сеток).
- Всё текучее через `clamp()` — размеры/отступы почти не имеют фиксированных
  значений между брейкпоинтами.
- Ховер-стили — только за `@media (hover: hover) and (pointer: fine)`.
- `--app-height` (JS-замер) вместо `100vh` — фикс мобильной адресной строки;
  safe-area-инсеты в `:root` (`--safe-top/right/bottom/left`), клин футера
  их учитывает.
- Мобильные заголовки слайдов `h2` — `position: sticky; top: 0` с чистой
  тенью (`text-shadow: 0 4px 18px rgba(0, 0, 0, 0.95), 0 2px 4px #000; filter: drop-shadow(...)`).
  Сплошные черные плашки `background: #000` и тяжелые `backdrop-filter: blur(...)`
  запрещены: размытие WebGL-канваса перегружало мобильные GPU и ломало рендеринг
  в Firefox для Android (Gecko). WebGL-символы заднего плана должны оставаться
  видимыми.
- Слайды `#about` и `#portfolio` на мобиле центрируются в safe-зоне (`margin: auto 0`).
- Карточки услуг на мобиле выстроены вертикально, размеры не мельчить (`min-height: 110px`,
  `padding: 20px 18px 46px`).
- `min-width: 320px` на body.

## i18n

- RU/EN, переключатель `.lang-switch-btn` на `#top` (RU / EN теги).
- Каждая строка живёт дважды: RU-литерал в `index.html` (фолбэк до JS) и в
  `translations.ru` (`site/src/i18n.js`). Атрибуты: `data-i18n` (textContent),
  `data-i18n-html`, `data-i18n-aria`, `data-i18n-alt`.
- RU-склонения только через `pluralRu(n, one, few, many)`.
- Событие `site-language-change` пересобирает форматированные строки
  (виджет и т.п.).

## Подстраница /generator

Свой `generator.html` + `generator.css`, но те же токены:
`--accent: #cedb1a`, `--panel-bg: #050505`, `--input-bg: #000`,
`--input-border: #333`, `--text-muted: #888`. Тот же шрифтовой стек
(Fira/Martian/Feature/Pixeloid Mono). Заголовок `// Генератор` с акцентными
слэшами, «кибер-бруталистичная» шапка с кнопкой `[ESC] НА ГЛАВНУЮ`,
страница `max-width: 1100px`, формы — сетки `settings-group`/`settings-grid`.
Свой спиннер-лоадер.

## Правила, которые нельзя ломать

1. Никаких фреймворков и новых зависимостей кроме Vite.
2. Четыре шрифта + Material Symbols — пятый только через явное обсуждение.
3. Новая CSS-переменная — отклонение; цвета брать из палитры выше.
4. Карточки: `2px solid #fff`, прямой угол; акцент — только `var(--accent)`.
5. Сетки — `minmax(0, …)` на треках и `min-width: 0` на карточках.
6. Комментарии в репозитории на русском.
7. `dist/` не редактируется руками — только `npm run build`.
8. Тон копи: короткий, фактический, слегка ироничный; без канцелярита и без
   CTA в `#about` (кнопки — в `#services`/`#links`).
9. Договор `contract.pdf` и скрипты генерации не пушатся в git и не выкладываются
   на сайт — хранятся только локально (`scripts/`, `*.pdf` в `.gitignore`).
   Текст условий для клиентов выводится прямо на сайте в блоке `.service-contract`.
